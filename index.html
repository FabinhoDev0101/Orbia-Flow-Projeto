Rede em VR

Explore uma rede de computadores em 3D. Gire o celular para olhar em volta.

Toque num círculo do chão para andar até ele. Toque num programa da barra para abrir ou fechar a janela dele. Segure a barrinha para mover a barra: arraste para baixo para trazer para perto e para cima para afastar. Toque duas vezes para cancelar.

A câmera abre por padrão como fundo, para o ambiente aparecer ao redor. Com a mão na frente da câmera, faça pinça com o dedo polegar e o indicador para clicar.

Para óculos de caixa, inicie e toque em Modo VR. O botão de volume do Cardboard também funciona como toque.

Vire o celular na horizontal para usar o modo VR.
Este aparelho ou navegador não conseguiu iniciar o 3D (WebGL). Tente abrir em outro navegador.
